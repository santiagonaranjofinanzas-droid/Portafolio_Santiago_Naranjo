[ [English Version](../README.md) ] | [ Versión en Español ]

## Resumen Ejecutivo

> [!NOTE]
> **Objetivo Principal:** Construir un framework de optimización de portafolios que elimine el ruido de estimación en la matriz de covarianza usando RMT y asigne pesos con HRP.

| Dimensión                  | Especificación                                                             |
| :------------------------- | :------------------------------------------------------------------------- |
| **Método de Optimización** | Hierarchical Risk Parity (HRP) + Single Linkage Clustering                 |
| **Filtrado de Ruido**      | Teoría de Matrices Aleatorias (RMT) mediante Distribución Marchenko-Pastur |
| **Stack Principal**        | Python, SciPy, Scikit-Learn, Seaborn, Matplotlib, Tiingo API               |
