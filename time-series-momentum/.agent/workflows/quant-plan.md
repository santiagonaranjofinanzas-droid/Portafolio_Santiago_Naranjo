#Quant Plan Workflow

Before writing code, produce a research implementation plan.

The plan must include:

1. Research hypothesis.
2. Target market/instrument/universe.
3. Data requirements.
4. Feature set.
5. Label definition.
6. Validation design.
7. Backtest assumptions.
8. Cost model.
9. Risk model.
10. Benchmark.
11. Expected failure modes.
12. Tests to be written before implementation.

Do not implement until the plan is explicit enough to audit.

The plan must include a "leakage risk table" with:

- possible leakage source;
- probability;
- severity;
- mitigation.
