#Contributing Guidelines - {{PROJECT_NAME}}

Thank you for contributing to {{PROJECT_NAME}}.

##Development Workflow
1. **Branching:** Create a descriptive branch name from `main` (e.g. `feat/new-indicator`).
2. **Coding Style:** Adhere to language-specific standard styles (e.g. PEP 8 for Python).
3. **Documentation:** Keep documentation (README, architecture, decisions) updated when adding new features or making changes.
4. **AI Assistance:** If working with an AI agent, ensure you run `start_project.bat` to maintain Graphify and Serena indexes.

##Pull Request Process
- Ensure all tests pass.
- Write meaningful commit messages.
- Request review from other project developers.
