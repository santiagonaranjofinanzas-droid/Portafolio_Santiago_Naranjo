#AI Developer Guide - {{PROJECT_NAME}}

This project is prepared for advanced agentic development using Google Antigravity and Codex tools.

##AI Tools Integrated

1. **Serena:** Semantic code symbol analysis is enabled under the `.serena/` directory.
2. **Graphify:** An AST-based semantic knowledge graph is available at `graphify-out/`.
3. **Workspace Customization (`.agents/`):** Contains rules and workflows loaded automatically by Antigravity.

##Recommended Prompts / Commands
- To search the graph: `/graphify query "your question"`
- To inspect symbol relations: `/graphify path "NodeA" "NodeB"`
- To check codebase structure, refer to [PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md).

Please follow the rules and guidelines defined in [AI_GUIDELINES.md](docs/AI_GUIDELINES.md) when writing or modifying code.
