## Executive Summary

> [!NOTE]
> **Core Objective:** Research non-linear macroeconomic shock transmission to financial market volatility by constructing a financial stress index (ISRI) via PCA and modeling state transitions with HMMs.

| Dimension                    | Specification                                                       |
| :--------------------------- | :------------------------------------------------------------------ |
| **Research Domain**          | Macro-Finance & Applied Econometrics                                |
| **Dimensionality Reduction** | Principal Component Analysis (PCA) for Economic Stress Index (ISRI) |
| **Econometric Models**       | Supervised Hidden Markov Models (HMM) & XGBoost Predictors          |
| **Presentation Format**      | Interactive HTML5 Document with MathJax Rendering                   |
| **Primary Stack**            | R (`tesis_pipeline.R`), Python, MathJax, Econometrics, HTML5        |
