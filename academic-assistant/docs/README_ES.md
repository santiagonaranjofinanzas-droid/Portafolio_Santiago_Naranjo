## Resumen Ejecutivo

> [!NOTE]
> **Objetivo Principal:** Proveer una plataforma web full-stack y un sistema de trabajadores locales para la automatización de horarios universitarios, tareas y alertas en Telegram.

| Dimensión           | Especificación                                                     |
| :------------------ | :----------------------------------------------------------------- |
| **Frontend**        | Next.js, React, TypeScript, Tailwind CSS                           |
| **Base de Datos**   | Supabase PostgreSQL con Row Level Security (RLS)                   |
| **Stack Principal** | TypeScript, React, Next.js, Supabase, Python, Telethon, Playwright |
