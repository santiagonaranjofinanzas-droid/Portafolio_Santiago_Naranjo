## Executive Summary

> [!NOTE]
> **Core Objective:** Provide a full-stack academic productivity platform and automated worker bot system for schedule scraping, deadline tracking, and Telegram notification alerts.

| Dimension              | Specification                                                         |
| :--------------------- | :-------------------------------------------------------------------- |
| **Frontend Framework** | Next.js, React, TypeScript, Tailwind CSS                              |
| **Database & Auth**    | Supabase PostgreSQL with Row Level Security (RLS)                     |
| **Automation Workers** | Python Scraper (`uni_scraper.py`), Telegram Bot (`telegram_agent.py`) |
| **Primary Stack**      | TypeScript, React, Next.js, Supabase, Python, Telethon, Playwright    |
