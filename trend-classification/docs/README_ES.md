## Resumen Ejecutivo

> [!NOTE]
> **Objetivo Principal:** Desarrollar un pipeline de Machine Learning para clasificación de tendencia mediante la regla de Triple Barrera y modelos de ensamble evaluados bajo CPCV.

| Dimensión                 | Especificación                                                         |
| :------------------------ | :--------------------------------------------------------------------- |
| **Técnica de Etiquetado** | Método de Triple Barrera (Take Profit, Stop Loss, Expiración Temporal) |
| **Modelos Evaluados**     | XGBoost, LightGBM, Random Forest, Regresión Logística                  |
| **Stack Principal**       | Python, Scikit-Learn, XGBoost, LightGBM, Parquet                       |
